## Qualification evidence

The [assertion mapping and reproduction harness](../planning/phases/0.4/evidence/qualification-2026-11-10/README.md)
map V04-01–26 to independent semantic, policy, presentation, interoperability,
input-limit, incremental, repair and synthetic-corpus controls. Exact source and
artifact identities and final CI runs are recorded below. The retained source run passed 480 Rust tests, 39 Python tests, 24 release controls, 23 configuration cases, eight consumer controls and all synthetic/static-tool controls. The raw archive contains 127 CLI records and 72 corpus reports; the successful full local check includes a second run from the packaged crate.

The new controls corrected generator result-use classification, baseline
whitespace/same-line site identity, exact-limit physical-input alias counting,
human-output byte bounds and broken stderr handling. Baseline algorithm 5 caches
canonical token/site anchors and retains resolved contract identity. Adoption
report/baseline construction rejects cancelled, inspection-only and lifecycle-only
results that claim unexecuted must-use rules. Snapshot identity includes analyzed
scope and rule/fingerprint revisions. The JSON schema independently checks that
scope claim, and the reference consumer verifies versions, current source,
selected-file attribution, counts, framing and stale/limited/error handling.
