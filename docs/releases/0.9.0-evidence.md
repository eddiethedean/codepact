## Performance comparison

The exact candidate ran the [V09-23 workloads](../planning/phases/0.9/performance.md)
against the published 0.8.0 source on macOS 26.5.2 ARM64 using Rust 1.96.0.
The capture alternated the process order across 24 baseline/candidate pairs
per workload. Each process measured seven trials.

The table shows paired median timing changes and the difference between the
two arms' maximum observed process RSS.

| Workload | Cold | Unchanged | Affected edit | Independent edit | Peak RSS change |
| --- | ---: | ---: | ---: | ---: | ---: |
| State | +0.90% | +0.54 µs (+8.31%) | +1.28% | −0.33% | +0.77 MiB |
| Exclusive access | +2.44% | +2.67% | +2.47% | +0.56% | +0.44 MiB |
| Executor | +2.95% | +2.26% | +3.08% | +1.39% | +0.77 MiB |
| Installed manifest | +0.83% | −1.15% | +1.48% | +1.36% | +0.39 MiB |

The largest relative increase was 8.31% on unchanged state analysis, or
0.54 µs. The largest absolute median increase was 2.12 ms for an affected
exclusive-access edit. The figures describe the named workloads on this host.

The two 64-function workloads added in 0.9 use pooled median timings.
Comparison starts with both captures already in memory.

| Workload | Cold capture | Unchanged capture | Affected edit | Independent edit | Comparison | Peak RSS |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MustHandle and repair review | 13.750 ms | 8.282 ms | 12.554 ms | 2.679 ms | 0.052 ms | 11.09 MiB |
| TaskGroup work observation | 30.773 ms | 14.647 ms | 31.170 ms | 12.865 ms | 0.091 ms | 14.09 MiB |
