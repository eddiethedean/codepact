# CodePact 0.5.0 candidate evidence

Status **local qualification of the development candidate**. Cross-platform
release qualification, exact-commit review, maintainer signoff and publication
are pending. The ownership preview has synthetic qualification on the local
candidate. Field usefulness remains unqualified.

## Candidate

- Version and phase are 0.5.0 and explicit ownership, lexical borrowing and
  structured task lifetimes.
- Base commit is `e5b6b26df701863e5eea5783b610929cd83a3385`. The implementation
  and qualification are in the working tree. The release record requires a
  concrete candidate commit before tag authorization.
- The retained source manifest has 168 entries and SHA-256
  `3bf96abea137a273fe7b64a8d1fc57e7b322c91d497b0952605353a43ff7c0f9`.
  The compressed evidence bundle has SHA-256
  `9e0ea5523bbe32b83621d94adfb89bfd19ae4ac9ea7949f0ec6c8b0ace0ab064`.
- Environment was macOS 26.5.2 arm64, Rust 1.96.0, and CPython 3.11.15 for the
  local quality command. Helper wheel installs also ran on CPython 3.12.13,
  3.13.16 and 3.14.3.
- The runtime model pins were exercised independently on CPython 3.11.15,
  3.12.13 and 3.13.16. Six probes per version covered non-eager scheduling,
  completion, inactive submission, cancellation before start, sibling
  cancellation and repeated cancellation while waiting.

## Local qualification

- `make check` passed with the offline dependency and advisory caches.
  It ran 524 Rust tests in the workspace and again from the packaged crate,
  46 Python tests, type and lint checks, dependency audit and MSRV checks,
  clean package installs, source-only checks, 12 live CLI JSON schema
  validations, and the strict Sphinx build. [Local quality log](../planning/phases/0.5/evidence/make-check.log.gz)
- The three ownership bug/repair pairs and one boundary project passed their
  source and installed CLI oracles for Python targets 3.11, 3.12 and 3.13.
  The 30 retained source and installed reports matched byte for byte. The
  repaired examples passed strict checks under the same semantic settings.
  All 27 project variants, including the inherited controls, passed strict
  Pyright and Ruff. The installed CLI also reproduced both tutorial
  findings and their strict-mode repairs. [Tutorial](../ownership.md)
- Fresh and reused checks agreed on the preview fixtures and across a provider
  edit that introduces a borrowed escape. The Salsa query-event control
  observed three initial file checks, two after the edit and zero on reuse.
- Native macOS arm64 and pure helper wheels passed matching-version,
  identity-helper, source-only checker and move-diagnostic smokes in clean
  installations on all four local interpreters. Both source distributions
  were built and installed under CPython 3.11.15.
- The optimized source CLI and installed wheel CLI both had SHA-256
  `37410069cb53506a888c18baf67c452272fdc4e58eb25863a0f0172141650d00`.
