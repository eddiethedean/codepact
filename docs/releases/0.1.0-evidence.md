## Review findings resolved

| Finding | Resolution and regression evidence |
| --- | --- |
| Eager class `global` writes leave stale contracts | Bounded traversal of eager class suites detects global declarations and invalidates the module view. Deferred method bodies are skipped. `eager_class_global_writes_invalidate_module_bindings`, `deferred_method_globals_do_not_invalidate_module_bindings`, and cached-consumer recovery cover direct, conditional, nested-class, walrus, and update/recovery cases. |
| Nested contracts silently disappear | Unsupported container annotations containing explicit or captured resource/access views produce `TP9001` and incomplete coverage. Plain non-resource generics remain accepted. `nested_contracts_are_visible_unsupported_boundaries` covers aliases, parameter/return annotations, and lifecycle metadata. |
| Submodule imports lose API identity | `from typepact import rust` and `contracts`, including aliases, resolve access and metadata identities. Rebinding removes identity and imported conflict spans remain accurate. Three submodule regression fixtures cover these behaviors. |
| Literal `None` annotations are incomplete | A distinct AST literal kind leaves ordinary `None` parameters/returns without synthetic contracts or diagnostics. Resource bases such as `Owned[None]`, computed expressions, and forward annotations remain unsupported. `none_annotations_are_ordinary_non_resource_types` and the CLI exit-status fixture cover the boundary. |
| Missing benchmark and candidate mapping | Corpus v1, measured baseline, and the V01–V24 mapping below are recorded. |
| Missing publishing environment | The `pypi` GitHub environment exists; no custom protection or deployment policy was invented. Both repository secret names are present. Credential values were not read. |
