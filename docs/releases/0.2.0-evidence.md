## Checks and preliminary evidence

On 2026-10-30, the complete local gate passed on Apple M4 Pro / macOS 26.5.2
ARM64 with rustc 1.96.0 and CPython 3.11.15. The command was:

```sh
uv run --locked make check CARGO_AUDIT_ARGS=--no-fetch CARGO_DENY_ARGS=--disable-fetch
```

The run passed formatting, Rust compilation and Clippy, 31 Rust unit tests, 22
CLI tests, 60 semantic fixtures, doc tests, 8 Python tests, type checking, lint,
dependency audits, Rust 1.96 MSRV, clean wheel/source and Cargo archive installs
with lifecycle smoke checks, documentation link checks (71 files), and the
strict Sphinx build. Cargo and UV used local dependency caches with network
access disabled; the audit tools used their no-fetch options. The local command
was run with these environment overrides:

```sh
PATH="/Volumes/T7/coding/typepact/.venv/bin:$PATH" \
CARGO_HOME=/private/tmp/typepact-cargo-home \
CARGO_NET_OFFLINE=true \
CARGO_TARGET_DIR=/private/tmp/typepact-release-target \
UV_CACHE_DIR=/private/tmp/typepact-check-uv-cache \
uv run --locked make check CARGO_AUDIT_ARGS=--no-fetch CARGO_DENY_ARGS=--disable-fetch
```

On 2026-10-31, the full local locked gate passed on the source and package
contents now frozen in candidate `58c51f31c9c8a5992fa95a37b13b81e2b16f0ca1`.
The full gate was run immediately before creating that commit; no source,
package, lockfile, or test changes were made afterward. The performance record
was updated from the final candidate build, then its links and strict Sphinx
build were rerun successfully. Environment: Apple M4 Pro, macOS 26.5.2 ARM64,
rustc 1.96.0, CPython 3.11.15. Command:

```sh

```

Results: formatting, Rust compilation and Clippy passed; 166 Rust tests passed
(32 library, 48 CLI, 60 semantic fixtures, 26 lifecycle regressions); all 8
Python tests, identifier-table, basedpyright, Ruff, mypy, and Pyright checks
passed. RustSec fetched 1,395 advisories and scanned 112 dependencies; `cargo
audit` and all cargo-deny advisory, ban, license, and source checks passed.
Rust 1.96 MSRV passed. The macOS ARM64 CLI wheel, pure helper wheel, and both
source distributions built at version 0.2.0 and passed Twine metadata checks;
clean local installs of each wheel and source distribution passed CLI version,
lifecycle, and no-execution smoke checks. The 24-file Cargo archive passed all
166 tests, release installation, inspector smoke, and lifecycle/no-execution
smokes. Documentation links passed for 73 files and strict Sphinx 8.2.3 passed.

These results are local Mac ARM64 / CPython 3.11 evidence. They do not qualify
the other supported Python versions or the eight-wheel platform matrix. The
[performance record](../planning/phases/0.2/performance.md) now records current
lifecycle timings, query-reuse tests, the inspector comparison, and process
high-water RSS. It identifies a 1.57× cold and 2.18×–2.47× edit-time increase
on the 1,000-resource corpus relative to earlier preliminary measurements, and
records the flow-state cloning optimization that reduced a 476 ms cold median
to 64.9 ms. No absolute latency threshold or reviewer acceptance has been
recorded. Retained-session memory remains unmeasured; flow limits remain
provisional pending LC01 review.

The [Quality workflow run 41166175547](https://github.com/eddiethedean/typepact/actions/runs/41166175547)
