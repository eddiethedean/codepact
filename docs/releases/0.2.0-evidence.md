## Qualification evidence

On 2026-11-01, `uv run --locked make check` passed on the implementation contents
at `654d7d4`; the later `e7a4f75` candidate changes only phase decision and
release-approval documentation. Exact-candidate CI passed on `e7a4f75`.
Environment: Apple M4 Pro, macOS 26.5.2 ARM64, rustc 1.96.0, CPython 3.11.15.

Results: formatting, Rust compilation and Clippy passed; 166 Rust tests passed
(32 library, 48 CLI, 60 semantic fixtures, 26 lifecycle regressions); all 8
Python tests, identifier-table checks, basedpyright, Ruff, mypy, and Pyright
passed. RustSec fetched 1,395 advisories and scanned 112 dependencies; cargo
audit and cargo-deny advisory, ban, license, and source checks passed. Rust
1.96 MSRV passed. Local package verification built the helper wheel, CLI wheel,
and both source distributions, checked Twine metadata, clean-installed all four
artifacts, and passed CLI, lifecycle, and no-execution smokes. The 24-file
Cargo archive passed its tests, release install, inspector smoke, and lifecycle
no-execution smoke. Documentation links passed for 73 files and strict Sphinx
8.2.3 passed.

The [performance record](../planning/phases/0.2/performance.md) contains exact
analyzer-source lifecycle and inspector measurements, query-reuse evidence,
process high-water RSS, and retained-session RSS. The 1,000-resource replay
measured 62.7 ms cold, 1.44 ms warm, 40.9–47.1 ms across edits, 37.30 MiB
process high-water RSS, and 19.50–19.73 MiB retained process RSS after dropping
diagnostics while keeping the session alive. Cold time is 1.57× and edit time
2.18×–2.47× higher than earlier provisional measurements. No absolute latency
threshold is defined. The accountable maintainer accepted these measurements and
the provisional flow limits with the limitations recorded in the performance
document on 2026-11-01 and waived independent review for this release.

Exact-candidate [workflow run 41260926690](https://github.com/eddiethedean/typepact/actions/runs/41260926690)
passed metadata checks, Python 3.11–3.14 quality, documentation, Rust quality
and dependency audit, source/Cargo package validation, all eight native wheel
builds with per-platform install/runtime smokes, and aggregate distribution
inventory/Twine checks. The two musllinux wheels also passed their pinned Alpine
runtime smokes. The branch run skipped all publication jobs. Separately, the
