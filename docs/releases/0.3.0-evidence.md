## Candidate automation evidence

On 2026-11-01, `uv run --locked make check` passed on candidate
`87eab93cd7fe5b7ac2b09a2ddd4bc1f42cd5611a` on CPython 3.14.3, macOS 26.5.2
ARM64. `cargo test --workspace --locked` passed 56 library, 51 CLI, 60
fixtures, 26 lifecycle regression and 116 phase tests; all 14 Python tests
passed. Formatting, workspace check, Clippy, Python
typing/lint, identifier-table checks, package wheel/sdist builds and install
smokes, dependency audit, MSRV, inspector behavior, documentation links and the
warnings-as-errors docs build passed. The separate Python checks passed on
CPython 3.12.13, 3.13.16 and 3.14.3. Exact-candidate Quality run 41303388459
passed Rust quality, dependency audit, documentation and Python 3.11–3.14 jobs.

The exact-candidate Release run 41303396907 built and smoke-tested all eight native
CLI wheels, built the pure helper wheel and both source archives, ran the Cargo
publish dry run, and passed full artifact inventory and metadata validation.
The verified bundle was downloaded and independently rechecked locally with
`scripts/verify_release_distributions.py` (eight CLI wheels, one pure wheel and
two source archives) and `twine check --strict` (all 11 artifacts passed). Its
hashes are recorded in the artifact table below. The workflow was dispatched
on the branch; all publication jobs were skipped.

The source CLI tutorial runs on this candidate produced the expected one
definite synchronous leak and cancellation-possible asynchronous findings.
Controlled `contextlib` runtime outcomes and source hashes are recorded in the
[conformance record](../planning/phases/0.3/contextlib-conformance.md). These
results establish automation behavior only; they do not constitute maintainer
semantic acceptance or pass a release gate.

The [performance record](../planning/phases/0.3/performance.md) measures the
candidate workloads on the release host after optimizing resolved-call state
transfer, source-span lookup and the bounded exit-partition worklist. At 1,000
resources, cold and edit medians are 0.46×–0.72× the accepted 0.2 baseline; the
250-resource medians are 0.71×–1.04×, with the warm no-op sample slightly above
baseline and edit samples below it.
Single-resource samples are small and noisy. The maintainer's G4 review remains
pending. No latency threshold has been defined by the phase plan.
