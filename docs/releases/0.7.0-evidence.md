## Findings and decisions

- The G4 follow-up did not reproduce the original 23% slowdown. Bypassing provider filtering on the no-provider fixture produced no measurable speedup. The cause of the historical gap remains unresolved. The follow-up was below the proposed 10% investigation threshold. The revised ten-pair harness measured +0.438 µs (+6.5%) for the flagged check. [Full paired harness replay](https://github.com/eddiethedean/codepact/blob/bc381f74a13373f751c613453ff4a58608a682ba/docs/planning/phases/0.7/evidence/exclusive-investigation/paired-harness-replay.json)
- The accountable maintainer approved publication once ready on 2026-11-17. The signed gates above record that condition as satisfied.
- The documented limits remain: TP5001 is off by default; installed-provider checking requires explicit dependency roots and a `py.codepact` marker; outcome payloads do not establish ownership, cleanup or task completion; general algebraic-data-type inference and automatic framework serialization are deferred.
- Tag run [44154694801](https://github.com/eddiethedean/codepact/actions/runs/44154694801) completed publication after the candidate Release run passed.
