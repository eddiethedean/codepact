# Earlier combined Pyrefly CLI proposal

Status: **Superseded on 2026-11-07** by the [TypePact combined product plan](typepact.md) and D020 in the [decision record](decisions.md).

The earlier proposal used `codepact-pyrefly-cli` for the PyPI distribution, `codepact-pyrefly` for the command, a first `0.1.0a1` prototype and `release-pyrefly.yml` for publication. Those are historical proposals, not current implementation or publisher claims.

The active plan retains pinned Rust embedding, the canonical CodePact engine, PF01–PF05 work packages and PF-V01–PF-V08 acceptance gates. It replaces the public names with TypePact, adds the main/helper dependency contract and migration from historical TypePact releases, and records the maintainer's acceptance of upstream API maintenance. Follow the active plan for current package, version, configuration, reporting and release decisions.

Previous publisher records must be reverified for the current repository and selected workflow; they do not establish ownership or a working publishing lane for the new product. No combined package or workflow is implemented or qualified by either planning document.
