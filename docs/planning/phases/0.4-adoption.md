Status: **CodePact 0.4.0 was published and verified on 2026-11-10.** A01–A08, CS02, and G1–G8 passed under the approved synthetic-preview scope. Real-world usefulness remains unqualified. [Release evidence](../../releases/0.4.0-evidence.md)

## Outcome

A developer can introduce CodePact into an existing repository, record existing findings explicitly, and make CI fail on new actionable findings under a visible, reproducible policy. Human readers, external editor tools and CLI agents receive the same findings, certainty and coverage. An empty filtered report must never imply that unsupported code was checked successfully.

0.4 builds on the published 0.3 cleanup checker. It adds adoption policy and the initial synchronous must-use rule; it does not qualify task ownership, broader resource models, a language server or MCP delivery.

Real-world usefulness is unqualified. Maintainer-approved AD01-A2 replaces the
field-pilot exit criterion with the [synthetic preview protocol](0.4/synthetic-preview-protocol.md).
The original field results remain insufficient and are retained as history.

## Scope and deliverables

| Deliverable | Required bounded behavior |
| --- | --- |
| Project configuration | Validated `[tool.codepact]`, explicit source target, deterministic discovery/path/rule policies, and inspectable effective settings |
| CI policy | Advisory/strict modes, configurable severity threshold, preserved certainty/coverage and documented 0/1/2 exits |
| Reporting | Published checker JSON Schema, capabilities, source/configuration/model identities, stable ordering, bounded details and a location-per-line format |
| Adoption controls | Reasoned rule-specific line suppressions and explicit baseline generation; no suppression of execution failures or loss of coverage |
| Must-use | Equivalent `@must_use`, `MustUse[T]` and verbose metadata; bare synchronous discard, assignment, propagation and explicit `discard` semantics |
| CLI agent workflow | Rule explanations, bounded repair evidence, stale/truncated-result detection and opt-in check–edit–recheck instructions |
| Qualification | Independent synthetic bug/repair and boundary projects including async, ordinary static-tool controls, clean onboarding, incremental/performance and exact-candidate distribution checks (AD01-A2) |

LE01 and the CLI portions of LE-V01/LE-V02 are mandatory reporting foundations. AI01–AI03 and CLI AI-V01–AI-V04 are mandatory through A08. CS02 enriches reports only with sites modeled by 0.3; unknown task/process handoffs remain boundaries. No TaskGroup lifetime violation or structured-task repair is required before CS03 qualifies that analysis in 0.5.

## Required exit gates

The maintainer approved A01–A08 and CS02 for the published synthetic preview. [Release evidence](../../releases/0.4.0-evidence.md)

- [x] **A01 — Reporting and exits.** Completed reports use documented policy-dependent 0/1 exits; invocation/configuration/execution failures use 2. Published versioned schemas, capabilities and text/JSON/concise fixtures agree on source locations, certainty, trust and coverage. Requires V04-02, V04-05–08, V04-18–19, V04-24–25 and CLI LE-V01/LE-V02.
- [x] **A02 — Baselines and suppressions.** Only matching eligible existing findings are hidden from the actionable set. New rules, changed evidence, ambiguous identities and changed semantic settings remain visible. Updates require an explicit operation; suppression cannot erase coverage or failures. Requires V04-09–11, V04-20–21.
- [x] **A03 — Configuration.** Invalid keys, types, targets, rule identifiers and schema versions fail clearly. Discovery, includes/excludes, physical containment and precedence have deterministic fixtures and inspectable effective values. Requires V04-01–04, V04-09, V04-24.
- [x] **A04 — Must-use.** Decorator, alias and verbose annotation lower to equal result-use obligations. Bare synchronous calls, explicit discard, assignment, forwarding, symbol identity and unsupported async/dynamic boundaries follow the specification. Lightweight helpers remain typing-compatible. Requires V04-12–16.
- [x] **A05 — Synthetic preview.** Pass the [AD01-A2 protocol](0.4/synthetic-preview-protocol.md): all 33 independent planted cases, eight source repairs and four boundary projects across three targets, ordinary static-tool controls and exact-artifact replay. Real-world usefulness remains unqualified. Requires V04-26.
- [x] **A06 — Readiness and inherited correctness.** No supported-scope correctness blocker or unexplained frontend disagreement remains. Clean onboarding reaches a useful check, a verified supported repair and CI behavior; published docs and distributions match the candidate. Requires V04-03, V04-07, V04-13–14, V04-16, V04-18, V04-22–24, V04-26 and inherited V03 regressions.
- [x] **A07 — Incremental policy correctness.** Source/target/model/rule/configuration/baseline changes refresh relevant findings, spans and coverage. Policy-only changes reuse semantic facts; fresh and reused sessions agree, with query-event evidence. Requires V04-10, V04-20–21, V04-24.
- [x] **A08 — CLI agent foundations.** Complete AI01–AI03 and CLI AI-V01–AI-V04: structured evidence preserves certainty/coverage, detects stale/truncated output and demonstrates repair without weakening project policy. Requires V04-04–08, V04-15, V04-17, V04-19, V04-21–25.
- [x] **CS02 — Async reporting and pilot.** Preserve modeled coroutine/resource origins, duty holder, close/return handoff, suspension and escape sites across reports and explanations. Include the synthetic async worker and unsupported concurrency controls under AD01-A2; report unsupported patterns separately. Require V04-17–18, V04-20, V04-26 and inherited fresh/reused async parity. This does not qualify CS03 task ownership.

## Deferred scope and handoff

Whole-program ownership, abandoned assigned-value tracking, Result/Option runtime types, async must-use consumption, automatic fixes, new third-party model catalogs and arbitrary dynamic dispatch remain outside 0.4. Structured task lifetime modeling begins in 0.5; LSP/editor clients, MCP services and persistent caches remain in 0.8. The optional TypePact combined product does not become a core adoption dependency.

Review A01–A08/CS02 together with G1–G8, publish changed default diagnostics and configuration/schema migration guidance, then authorize the tag separately. 0.4.x retains these obligations and adds regression evidence. Hand canonical reporting/settings/fingerprint contracts to later ownership and integration work under the [shared architecture](../architecture.md), [query specification](../analyzer-migration.md) and [root roadmap](../../../ROADMAP.md).
