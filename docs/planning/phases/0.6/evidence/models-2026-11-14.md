The implemented TaskGroup model claims CPython 3.11–3.13 and uses the
version-specific submission behavior represented by these pins. The local
executor model claims only CPython 3.13.16; hashes for other executor files
are recorded for comparison, not as support claims. The executor probes
exercise only direct `ThreadPoolExecutor` submit and shutdown behavior without
tracked worker captures or resource arguments.

## Controlled conformance results

| CPython | Advanced helper tests | TaskGroup probes | ThreadPoolExecutor probes |
| --- | ---: | ---: | ---: |
| 3.11.15 | 3/3 passed | 6/6 passed | Not claimed; 5 skipped by pin guard |
| 3.12.13 | 3/3 passed | 6/6 passed | Not claimed; 5 skipped by pin guard |
| 3.13.16 | 3/3 passed | 6/6 passed | 5/5 passed |

The TaskGroup probes cover default-factory behavior, cancellation before
startup, inactive submission and coroutine state, sibling cleanup on child
failure, repeated parent cancellation, and cancellation during awaited
cleanup. The executor probes cover normal submit and waiting shutdown,
repeated shutdown and rejected post-shutdown submit, nonwaiting shutdown,
thread startup failure with queued work, and join failure after the shutdown
flag changes.

Reproduce with these interpreter-specific commands:

```sh
PYTHONPATH=python uv run --no-project --python 3.11.15 --with typing-extensions==4.16.0 python tests/python/test_advanced_helpers.py
uv run --no-project --python 3.11.15 python tests/python/test_task_group_model_conformance.py
PYTHONPATH=python uv run --no-project --python 3.12.13 --with typing-extensions==4.16.0 python tests/python/test_advanced_helpers.py
uv run --no-project --python 3.12.13 python tests/python/test_task_group_model_conformance.py
PYTHONPATH=python uv run --no-project --python 3.13.16 --with typing-extensions==4.16.0 python tests/python/test_advanced_helpers.py
uv run --no-project --python 3.13.16 python tests/python/test_task_group_model_conformance.py
PYTHONPATH=python uv run --no-project --python 3.13.16 --with typing-extensions==4.16.0 python tests/python/test_thread_pool_model_conformance.py
```

The executor probes deliberately inspect CPython's private worker and queue
state to test the represented failure paths. Those tests are conformance
evidence for the exact pin; they do not imply that the analyzer models worker
completion, joins, queued work, or cleanup.
