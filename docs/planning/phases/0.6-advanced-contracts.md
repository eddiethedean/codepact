# 0.6 — Exclusive access, typestate and effects

Status **Preview implementation complete; maintainer acceptance pending**. The updated candidate retains the advanced synthetic corpus, TaskGroup/coroutine budget controls, query-event evidence and stress measurements. Cross-platform distribution qualification for the frozen candidate is tracked in the [candidate release record](../../releases/0.6.0-evidence.md). Legacy mapping is M4 / implementation Phase 4.

## Outcome

Developers can opt into checking exclusive access to a modeled object, whether a call is valid in its current protocol state, and what the call can change on each exit. The initial models cover bounded synchronous calls, suspension boundaries, the existing structured TaskGroup subset and a local executor submission/shutdown protocol. Findings identify the conflicting borrow, transition or unresolved effect.

## Required exit gates

- [ ] **T01 — Exclusive access.** Reject known conflicts with shared or exclusive access and alias mutations during a live exclusive region. Report unresolved exclusivity as incomplete coverage. Requires V06-04–05.
- [ ] **T02 — Declaration parity.** Equivalent Pythonic and explicit declarations lower identically. Invalid and contradictory declarations fail before flow uses them. Requires V06-02–03.
- [ ] **T03 — State joins.** Retain finite alternatives at joins and distinguish definite and possible precondition violations. Requires V06-07.
- [ ] **T04 — Completion effects.** Apply normal, exceptional and cancelled effects on their respective edges, with original cleanup duties intact where discharge is unproved. Requires V06-08, V06-11–12.
- [ ] **T05 — Unknown and recursive effects.** Unresolved effects yield incomplete coverage. Recursive checking converges or widens under explicit limits. Requires V06-09–10.
- [ ] **T06 — Suspension.** Surface a live exclusive region spanning await or yield, including relevant implicit async suspension. Apply mode policy to unsupported coverage. Requires V06-06, V06-14.
- [ ] **T07 — Invalidation.** State, effect, model and location edits refresh dependent evidence. Bound analysis and preserve fresh/reused parity and unrelated reuse. Requires V06-10, V06-13, V06-16.
- [ ] **CS04 — Concurrent protocols.** Qualify modeled overlap and suspension boundaries, finite TaskGroup and local pool states, and their completion effects. Requires V06-04, V06-06, V06-11–14. [Concurrency gate](../concurrency.md#release-mapping-and-required-gates)

## Deferred scope

General lifetime relations, returned borrows, state-dependent field guarantees, arbitrary predicates, effect polymorphism, generator execution, dynamic scheduling, thread/process ownership, and lock or race-freedom proofs remain deferred. Typed outcomes remain in [0.7](0.7-typed-outcomes.md).
