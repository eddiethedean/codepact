message from admission to receipt and any resulting accounting duty. Track
worker completion, result observation and local cleanup independently.

## Release gates

The [concurrency plan](../concurrency.md#new-stdlib-semantic-gates) defines
AS04–AS05 and MP04–MP05. PC07 evidence in this release covers the bounded
composition in V10-15. [Portfolio workstreams](../contract-and-portfolio-workstreams.md)

- **AS04** — Qualify asyncio Queue item and accounting effects, cancellation, and both shutdown modes.
- **AS05** — Qualify bounded asyncio locks, semaphore permits, condition guards and event signals, including failed or cancelled acquisition and guard violations.
- **MP04** — Qualify the separate multiprocessing IPC and cleanup protocols, including feeder failure, local endpoint copies, receipt and accounting.
- **MP05** — Qualify explicit spawn entry, argument and context controls, selected synchronization primitives, and the exact guards for bounded Value/Array compound updates.
- **E04** — Record pinned runtime artifacts, applicability and maintained conformance fixtures for each promoted model.
- **E05** — Qualify the helper, CLI extra, native wheels, source archives and optional Cargo route.

## Scope boundaries

The claim covers modeled operations on resolved actors, messages and guards.
Dynamic graphs, escaped aliases, unreviewed callbacks and other runtime
profiles produce coverage boundaries. Copies of plain messages carry their
own receiver identity. Shared-memory ownership, advanced shutdown and
thread/executor bridges follow in [0.11](0.11-shutdown-and-bridges.md).

## Evidence and release decision

Record the exact candidate, runtime and model identities, valid, invalid and
unknown fixtures, diagnostics and coverage, reuse parity and analysis costs.
Keep runtime probes limited to repository-owned code and analyze target
projects from source. [Release evidence template](../release-evidence-template.md)
