### Finite matches

Check `match` only when supported flow establishes a closed set of CodePact
outcome variants. Start with resolved constructors, local assignments and
joins, and resolved `Result` or `Option` signatures where the supported
contract establishes the closed set. If an unknown input, a possible subtype
outside the modeled set, or a rebound identity prevents that proof, report
incomplete coverage for the affected check.

| Case | Expected result |
| --- | --- |
| Reachable unguarded variant patterns with no payload test, or only payload captures or wildcards | Each arm covers its entire resolved variant. A known reachable variant left uncovered is diagnosed. |
| Simple OR of supported variant patterns | Covers the union of its supported alternatives if unguarded. |
| Unguarded wildcard or capture arm | Covers all remaining reachable variants of a known closed set. |
| Guarded arm | Supplies no unconditional coverage. A later unconditional arm can cover the same variant. |
| Variant ruled out by supported flow, or arm after unconditional coverage of its alternatives | Does not affect the remaining coverage. |
| Nested payload tests, other unsupported patterns or unresolved scrutinee or pattern identity | If the result depends on the unsupported case, report incomplete coverage. Preserve any independently established missing variant. |

### Resource payloads

Tracking ownership through outcome payloads is deferred to [TypePact TC03](../typepact.md#tc03--combine-payload-typing-with-obligation-tracking).
When a modeled resource enters an outcome and further tracking depends on
payload semantics, report incomplete coverage for the affected obligation.
Wrapping, assignment, matching, extraction, forwarding and discarding provide
no proof of cleanup, ownership transfer or task completion. Keep independently
established findings and unrelated duties visible. Apply existing must-use
semantics separately from payload coverage.

Qualify adapter behavior around async work under [CS05](../concurrency.md#release-mapping-and-required-gates). The [proposed conversion semantics](0.7/specification.md#explicit-conversions) define exception propagation and the task boundary.

## Required exit gates

- [x] **R01** — Runtime and pinned type-checker fixtures agree on construction, payload access, narrowing and generic assignment rules.
- [x] **R02** — Conversions have round-trip cases and explicit lossy cases, including `Some(None)` versus absence.
- [x] **R03** — Exception adapters capture eligible instances of declared exception classes. Cancellation, process-control exceptions and exception groups propagate unchanged.
- [x] **R04** — Qualify each finite-match case above. Include both outcome families, a guarded fallback, a flow-unreachable variant, a shadowed class, and an unresolved or open scrutinee.
- [x] **R05** — There is no implicit exception swallowing or automatic unwrap. Runtime variants integrate with both public namespaces without duplicate class identities.
- [x] **R06** — Core resource and ownership fixtures still pass. With a modeled resource in `Ok`, `Err` or `Some`, exercise construction, assignment, match/extraction, forwarding and discard. Verify visible incomplete coverage wherever payload tracking is needed, independently established findings, and no inferred transfer, cleanup or task completion. Include an ordinary payload as a control.
- [x] **R07** — Changes to outcome identities, signatures and adapter summaries refresh affected exhaustiveness and obligation diagnostics with fresh/reused parity. Retain scoped invalidation evidence.
- [x] **R08** — In clean environments, `pip install codepact` installs the typed helpers without a native CLI dependency or executable. `pip install 'codepact[cli]'` resolves the exact matching CLI and passes import and command smoke checks. `pip install codepact-cli` supplies a working standalone command. Verify wheel and source routes, CLI platform coverage, and migration of a project that previously relied on the implicit CLI.
- [x] **R09** — A marked wheel installed outside its checkout yields `TP3001` and provider evidence for a discarded result through a supported import or re-export. Handling the result, disabling dependency checking, and selecting an unmarked or shadowing provider exercise the corresponding controls. Verify explicit environment selection, no target execution, relevant unresolved coverage, and CLI/Rust parity.
- [x] **R10** — Verify signature, return and acquisition locations for the missing ownership diagnostic. Suggest `Owned[T]` for a uniform open-owned handoff and exercise borrowed, closed, mixed and `finally` cleanup controls. A resolved `contextlib.closing` call gives one declaration hint per eligible local class, with none for a shadowed lookalike. A direct synchronous forward of a resolved must-use result gives a hint, with a rebound or unrelated callable as a control. Hint-only cases leave advisory and strict exit status unchanged.
- [x] **CS05** — Complete the phase requirements in the [concurrent resource safety plan](../concurrency.md); retain valid, invalid and unsupported-boundary fixtures and fresh/reused parity for the claimed subset.
