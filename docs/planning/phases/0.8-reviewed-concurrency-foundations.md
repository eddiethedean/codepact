## Required exit cases

- [ ] **AS01–AS02** accept established completion before cleanup and diagnose a known live borrower at cleanup. Preserve obligations for an unawaited coroutine, scheduling failure, cancellation before start, interrupted wait/cleanup, timeout and unfinished structured siblings. A shielded wait cannot fabricate underlying completion.
- [ ] **MP01** distinguishes unstarted, started, completed and closed local handles. Cover duplicate start, premature close, failed start, timed join and worker failure. A false is_alive result is not termination evidence for an unstarted process; a timed join returning does not prove completion.
- [ ] **MP02** covers valid submission, failed submission, submission after shutdown, close/terminate followed by the appropriate join and exceptional context exit. Forced Pool shutdown must not masquerade as graceful work completion or observation of every result.
- [ ] **E11** passes in full under the unchanged [definition](carry-forward-gates.md#e11). Stale, ambiguous and unknown providers retain incomplete coverage; malformed/conflicting files retain the specified error behavior.
- [ ] CR01/OH01 accept the linked v1 specifications, including nonpassing preservation conditions and opt-in marked-return production. Unmarked outcomes and released MustUse behavior retain their compatibility controls; unsupported declaration positions stay explicit. PC06 records complete named scopes and budget limits without claiming unsupported siblings were checked.
- [ ] Library LC01–LC04, LC06 and applicable LC08/PC01 evidence includes valid, invalid and boundary fixtures. Inline/manifest forms normalize equally; model/provider edits invalidate callers, provenance and locations.
- [ ] **E10-A** passes the mandatory [artifact and author-workflow checkpoint](carry-forward-gates.md#mandatory-e10-checkpoints). An author exports staged contracts with the installed CLI, explicitly builds provider wheels, verifies the actual wheels with the installed CLI, and checks an independently installed caller. Exercise artifact mismatch, stale/invalid metadata and unknown capabilities; unqualified facts cannot establish cleanup or ownership. Export, verification and analysis never import or execute the target package. Record CLI/Rust upgrade/shadowing parity and fresh/reused results. Command spellings remain provisional; the workflow is required.
- [ ] E04/E05 apply to every claimed integration and artifact. E10-A must pass before the 0.8 release; record its evidence without marking the composite E10 gate complete.

## Scope boundaries

Serialized plain values are not an ownership move. Worker-local construction establishes only the separately modeled worker resource; it does not transfer the parent's connection, file, lock or native handle. Fork, forkserver, custom reducers, inherited handles and unsupported platforms remain explicit boundaries until separately qualified. The analyzed configuration, not checker-host defaults, selects the start method.

Completion, exception observation, typed-result acknowledgment and resource cleanup remain separate. Persistent MustHandle acknowledgment is 0.9 work. Persistent caching, editor delivery and MCP remain explicit 0.12 commitments.
