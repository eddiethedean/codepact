# 0.5 — Explicit ownership and lexical borrowing

Status **Implemented in the 0.5.0 development candidate**. The preceding release is qualified. The required 0.5 gates await exact-candidate evidence review and maintainer signoff. Legacy mapping is M3 / implementation Phase 3.

## Outcome

A developer can opt into checking who may use or close a modeled resource, where its cleanup duty moves, and when a scoped borrower has finished. The first slice covers explicit local and call-boundary transfers, lexical shared borrows, and resource captures in a qualified subset of `asyncio.TaskGroup`. A report identifies the move, conflicting alias, borrow, or completion boundary that determines the finding.

## Required exit gates

- [ ] **O01 — Move and reuse.** A supported move invalidates the source handle and carries the existing duty to the receiver. Reuse and double transfer are diagnosed. Requires V05-02–04 and V05-08.
- [ ] **O02 — Evaluation and cleanup.** A move takes effect at argument evaluation. Subsequent argument failure, binding failure, callee raise or failed scheduling preserves the committed move, with cleanup accounted for at the actual exit. Moving leaves lifecycle state intact. Requires V05-03–05, V05-08 and V05-12.
- [ ] **O03 — Aliases.** Assignment retains Python alias semantics. Known conflicting live aliases and active borrows block a claimed unique transfer. Requires V05-06 and V05-11.
- [ ] **O04 — Lexical shared borrowing.** Supported callee bodies enforce non-consumption, non-close and non-escape, with checked entry and exit effects. Requires V05-07–08 and V05-11.
- [ ] **O05 — Conservative boundaries.** Unknown/native calls, container storage and closure capture never establish uniqueness. Strict mode rejects unresolved relevant boundaries. Requires V05-07, V05-09, V05-12 and V05-14.
- [ ] **O06 — Parity and bounded effects.** Equivalent and mixed-interface contracts agree through local and supported interprocedural flows, including recursion and analysis limits. Requires V05-01, V05-08, V05-10 and V05-13.
- [ ] **O07 — Invalidation.** Changes to transfer, escape, completion or provenance facts refresh dependent checks. Location-only edits refresh evidence, and unrelated checks can reuse work. Requires V05-13 and V05-16.
- [ ] **CS03 — Structured task lifetimes.** Qualify the pinned TaskGroup subset with valid, invalid and unresolved controls, including normal and exceptional group exit, pre-start cancellation, and fresh/reused parity. Requires V05-11–13 and V05-15. [Concurrency acceptance](../concurrency.md#release-mapping-and-required-gates)
