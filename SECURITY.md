# Security policy

CodePact parses selected Python source locally. See the
[security and data-handling guide](docs/security.md) for input scope, report
contents, and limits.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting form](https://github.com/eddiethedean/codepact/security/advisories/new).
Include the affected version, platform, impact, and a minimized reproduction.
Keep vulnerability details and sensitive source in the private report.

The project publishes no response-time SLA, supported-version window, or
guaranteed backport policy. The maintainer determines the affected releases
and remediation plan after triage.
