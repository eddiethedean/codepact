# Security policy

TypePact parses selected Python source locally without importing or executing
the analyzed application. See the [security and data-handling guide](docs/security.md)
for input scope, report contents, and limits.

## Reporting a vulnerability

If GitHub's **Report a vulnerability** option is available in this repository's
Security tab, use it to submit details privately. If the option is unavailable,
open a public issue with only a request for a private reporting route. Do not
include vulnerability details, exploit code, or sensitive source in a public
issue.

The project does not publish a response-time SLA, supported-version window, or
guaranteed backport policy. The maintainer will determine the affected releases
and remediation plan after triage.
